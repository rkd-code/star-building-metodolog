# Инструкция для Ветки 1: «Заявки и черновики регламентов»

Ветка предназначена для **всех сотрудников компании** (прорабов, мастеров, инженеров, бухгалтеров, менеджеров, юристов).

---

## Сценарий А. Если у сотрудника есть готовый набросок / черновик
- **Как отправить:** Надиктовать голосовое сообщение, написать текст своими словами или прикрепить файл (`.docx`, `.pdf`, заметку).
- **Что делает агент:**
  1. Нормализует роли по Оргструктуре (`РЕГ-002`).
  2. Проверяет соответствие Кодексу (`РЕГ-001`).
  3. Упаковывает процесс строго в **5 обязательных разделов**.
  4. Задает уточняющие вопросы автору по белым пятнам (сроки, формы).
  5. Передает проект в папку `01_В_РАБОТЕ` для согласования рабочей группой.

---

## Сценарий Б. Заявка на разработку документа с нуля
Если процесс еще нигде не описан, но в компании возникла регулярная проблема, сотрудник пишет заявку в свободной форме:
> *«Нужен регламент / инструкция / должностная инструкция / шаблон документа на тему: [описание потребности]».*

### Пример заявки:
> *«Нужна должностная инструкция для помощника геодезиста на объекте и шаблон акта проверки разбивочной основы».*

### Алгоритм диалога агента при заявке с нуля:
1. Агент благодарит за инициативу и задает 3 целевых вопроса:
   - *Кто главный исполнитель и кто принимает результат?*
   - *Какие ключевые этапы или требования к качеству обязательны?*
   - *В какие сроки должен выполняться процесс?*
2. На основе ответов сотрудника агент сам генерирует первичный проект стандарта по 5 разделам.
