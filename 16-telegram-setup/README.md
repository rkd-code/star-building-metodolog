# 16-telegram-setup: Настройка и регламент Telegram-группы

В каталоге зафиксирована структура официальной группы Telegram Star Building для всех сотрудников компании.

---

## 🏛️ Структура 2 официальных веток

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│          ОФИЦИАЛЬНАЯ ГРУППА TELEGRAM «STAR BUILDING — СТАНДАРТЫ»            │
│                     (Доступна ВСЕМ сотрудникам компании)                    │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │
            ┌──────────────────────────┴──────────────────────────┐
            ▼                                                     ▼
  [ВЕТКА 1: ЗАЯВКИ И ЧЕРНОВИКИ]                         [ВЕТКА 2: ВОПРОСЫ И КОНСУЛЬТАЦИИ]
  • Доступ: ВСЕ сотрудники компании                     • Доступ: ВСЕ сотрудники компании
  • Сценарий А: Подача готового черновика               • Сценарий: Задать рабочий вопрос
    (текст, голос, файл .docx) ➔ упаковка 5 разделов    • Результат: Пошаговый порядок действий
  • Сценарий Б: Заявка на разработку с нуля:            • Обоснование: Пункты РЕГ-001..010
    - Регламента процесса                               • Автогенерация документов:
    - Должностной инструкции                              - Служебная записка
    - Технологической карты / инструкции                  - Коммерческий акт дефектовки
    - Шаблона документа / формы                           - Заявление на отпуск/командировку
```

---

## Инструкция по созданию группы:

1. Создать супергруппу в Telegram: **«Star Building — Регламенты и Стандарты»**.
2. Включить опцию **«Темы» (Форум)** в настройках группы.
3. Создать 2 ветки:
   - 📝 **Тема 1: `Заявки и черновики регламентов`**
   - ❓ **Тема 2: `Вопросы и консультации`**
4. Добавить бота и выдать права администратора для чтения и отправки сообщений.
