# Модель данных сервиса «Экзаменатор Star Building»

## 1. Вопрос

Идентификатор: `ВОП-000001`.

Обязательные поля:

- тема;
- формулировка;
- тип;
- сложность;
- статус;
- версия;
- ссылка на источник;
- пункт источника;
- объяснение правильного ответа;
- автор;
- проверяющий;
- дата проверки.

Статусы: `Черновик`, `На проверке`, `Действует`, `Приостановлен`, `Архив`.

Типы: один ответ, несколько ответов, верно/неверно, последовательность, ситуационная задача.

## 2. Вариант ответа

Идентификатор: `ОТВ-ВОП-000001-А`.

Поля:

- вопрос;
- код варианта;
- текст;
- признак правильности;
- вес;
- порядок.

Признак правильности никогда не передается в интерфейс до завершения попытки.

## 3. Программа тестирования

Идентификатор: `ПРОГ-0001`.

Поля:

- название;
- назначение;
- должности из утвержденной оргструктуры;
- темы;
- число вопросов;
- ограничение времени;
- порог прохождения;
- число попыток;
- период доступности попыток;
- срок действия результата;
- состояние;
- версия.

Для первого пула зафиксированы: порог 90%, одна попытка в месяц, срок действия результата — до запроса РОПа на повторное прохождение. Число вопросов и время одной попытки пока не указаны.

## 4. Назначение

Идентификатор: `НАЗН-ГГГГММДД-0001`.

Поля:

- сотрудник;
- программа;
- дата назначения;
- крайний срок;
- назначившее уполномоченное лицо;
- состояние;
- основание.

## 5. Попытка

Идентификатор: `ПОП-ГГГГММДД-000001`.

Поля:

- назначение;
- сотрудник;
- программа и ее версия;
- время начала;
- время завершения;
- состояние;
- итоговый балл;
- статус прохождения;
- контрольная сумма состава вопросов.

Состояния: `Создана`, `Выполняется`, `Завершена`, `Истекло время`, `Аннулирована`.

## 6. Вопрос попытки

Хранит неизменяемый снимок:

- код и версию вопроса;
- формулировку;
- варианты без служебных данных;
- порядок;
- максимальный балл;
- ссылку на источник.

Снимок нужен, чтобы последующее изменение банка не меняло старый результат.

## 7. Ответ сотрудника

Поля:

- попытка;
- вопрос попытки;
- выбранные варианты или текст;
- время ответа;
- начисленный балл;
- результат автоматической проверки;
- отметка ручной проверки, если она требуется.

## 8. Результат по теме

Поля:

- попытка;
- тема;
- набранные баллы;
- максимальные баллы;
- процент;
- рекомендуемые документы для повторения.

## 9. Журнал аудита

Идентификатор: `АУД-ГГГГММДД-000001`.

Фиксирует:

- действующее лицо;
- время;
- действие;
- объект;
- предыдущее и новое состояние без секретов;
- основание;
- сетевой адрес и технические сведения в пределах утвержденной политики.

## 10. Ограничения целостности

1. Действующий вопрос обязан иметь утвержденный источник и проверяющего.
2. Правильный ответ нельзя изменить внутри существующей версии.
3. У завершенной попытки нельзя менять состав вопросов и ответы.
4. Результат вычисляется только из снимков вопросов попытки.
5. Сотрудник не может получить доступ к чужой попытке.
6. Удаление сотрудника из активного списка не уничтожает нормативно необходимую историю результатов.
7. Срок хранения персональных данных: `[ТРЕБУЕТ УТОЧНЕНИЯ: определить совместно с ответственными за кадры, безопасность и правовое обеспечение]`.
