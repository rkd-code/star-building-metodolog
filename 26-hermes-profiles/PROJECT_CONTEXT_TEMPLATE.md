# Шаблон контекста проекта для обоих профилей

Размещайте этот файл как `.hermes.md` в корне каждого репозитория. Hermes обнаруживает `.hermes.md` от текущей папки до корня Git.

```markdown
# <Название проекта>

## Назначение
<Какую задачу решает проект и кто его пользователи>

## Репозиторий
- Основная ветка: <main/master/...>
- Команда установки: <команда>
- Команда запуска: <команда>
- Узкие испытания: <команда>
- Полные испытания: <команда>
- Сборка: <команда>

## Правила изменений
- <стиль и архитектурные ограничения>
- <правила миграций>
- <правила совместимости>

## Документы управления
- KNOWLEDGE_BASE.md
- DECISIONS.md
- PROJECT_MAP.md
- <другие реестры>

## Graphify
- Граф: `graphify-out/graph.json`
- Перед чтением большого числа файлов выполнить `graphify query`.
- После изменения кода выполнить `graphify update .`.
- Каталог `graphify-out/`: <отслеживается Git / локальный, исключен из Git>

## Безопасность
- Секреты хранятся только в <защищенном хранилище или .env вне Git>.
- Запрещены принудительная отправка, самостоятельное развертывание и необратимые операции.

## Готовность задачи
- Реализация завершена.
- Испытания пройдены.
- Diff проверен.
- Документация и Graphify обновлены.
- Рабочая ветка отправлена в удаленный репозиторий.
```
