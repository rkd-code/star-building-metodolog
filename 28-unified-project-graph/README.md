# 28-unified-project-graph: Единый граф проектов и знаний

## Назначение

Каталог содержит нормализованный реестр проектов, людей, репозитория, документов, решений и связей для построения единого графа Graphify.

## Состав

- `PROJECT_REGISTRY.md` — карточки P-001..P-010 с обязательными полями.
- `RELATIONSHIPS.md` — явные отношения между проектами, людьми, документами, репозиторием и ADR.
- `/home/roman/graphify-out/graph.json` — машиночитаемый граф Graphify: 186 узлов, 190 связей, 52 сообщества.
- `/home/roman/graphify-out/GRAPH_REPORT.md` — отчет о структуре графа.
- `/home/roman/graphify-out/graph.html` — автономное интерактивное представление без внешних библиотек.

## Область инвентаризации

Проверены:

- рабочий каталог `/home/roman`;
- Git-репозитории внутри него;
- публично доступные репозитории GitHub пользователя `rkd-code`;
- реестры Hermes Projects профилей `default` и `developer`;
- корневые архитектурные документы;
- описания основных рабочих направлений и интеграций.

В текущей среде найден один самостоятельный Git-репозиторий — `rkd-code/star-building-metodolog`. Поэтому направления P-002..P-010 представлены как связанные проекты и составные части единого монорепозитория, а не как вымышленные отдельные репозитории.

## Безопасность

- Пароли, токены и закрытые ключи в реестр и граф не включаются.
- В исходном коде Telegram-прототипов учетные данные заменены переменными окружения.
- Graphify сканирует только рабочий репозиторий и исключает скрытые каталоги с учетными данными.
- Отсутствующие сведения маркируются «не указано».

## Обновление

После структурного изменения проекта:

```bash
cd /home/roman
graphify update .
```

После автоматического обновления необходимо повторно выполнить `build_curated_graph.py`, собрать `curated-graph.json`, объединить его с основным графом командой `graphify merge-graphs`, нормализовать результат через `build_curated_graph.py --normalize graphify-out/graph.json` и выполнить `graphify cluster-only`. Это сохраняет обязательные карточки `P-001`..`P-010` без дублей, даже если семантическая модель пропустила часть документов.

После добавления нового самостоятельного проекта:

1. добавить карточку в `PROJECT_REGISTRY.md`;
2. добавить связи в `RELATIONSHIPS.md`;
3. зарегистрировать репозиторий в Hermes Projects;
4. обновить Graphify;
5. проверить проект запросом `graphify query`.
