# 18-bot-behavior-refinement: Регламент выдачи шаблонов документов

В каталоге зафиксированы новые правила поведения бота-консультанта при работе со служебными документами:

---

## 1. Запрет на генерацию не утвержденных форм
- Бот имеет право ссылаться и выдавать шаблоны **только тех документов**, которые прямо зафиксированы в реестре базы знаний (`reestr-reglamentov.md` / `ФОРМА-ХХХ`).
- Категорически запрещено выдумывать произвольные формы от себя.

---

## 2. Интерактивный запрос перед формированием документа
- Бот не выдает простыню текста документа сразу.
- **Алгоритм ответа:**
  1. Пошаговые действия (*что делать / что запрещено*).
  2. Нормативное обоснование со ссылкой на пункт регламента.
  3. Вопрос сотруднику:  
     *«Для фиксации этой ситуации по регламенту РЕГ-ХХХ требуется оформить [Название документа]. Подготовить для вас готовый заполненный шаблон?»*
  4. Только после подтверждения сотрудника («Да», «Подготовь», «Нужно») бот генерирует предзаполненный текст служебной записки или акта.
