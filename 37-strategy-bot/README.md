# 37 — «Драмкнот»: стратегический бот Star Building

Отдельный закрытый Telegram-бот для работы руководителя со стратегией, показателями, рисками и управленческими решениями. Он не заменяет «Смотрителя» и «Ома» и не загружает их стратегическим контекстом.

## Границы

- Только пользователи из явного списка Telegram ID.
- Только три разрешённых источника: `STRATEGY.md`, `PRESENTATION_THESES.md`, `BUDGET_RATIONALE.md`.
- Стратегия и бюджет всегда обозначаются рабочими материалами, а не утверждёнными регламентами.
- Бот не меняет канонические файлы, не утверждает решения, не публикует материалы и не создаёт обязательства.
- Факты, расчёты, предложения, риски и решения разделяются явно.

## Возможности

- ответы по стратегии текстом;
- команды `/status`, `/risks`, `/decisions`, `/clear`;
- голосовые сообщения;
- файлы MD, TXT, DOCX, PDF, PNG и JPG;
- краткая память диалога в оперативной памяти;
- расширение P-026 («Коммерческий департамент»):
  - `/project` (или `/p026`) — сводный статус, нормативные лимиты и версии документов КД;
  - `/record_decision <текст>` — изолированная фиксация явного решения владельца в журнале;
  - `/export_draft <тип>` — безопасная выгрузка версионного черновика без перезаписи оригиналов;
- безопасный отказ всем пользователям вне списка доступа.


## Развёртывание

1. Создать нового бота через BotFather.
2. Скопировать `env.template` в `/home/roman/.config/star-building/strategy-bot.env`.
3. Заполнить токен, имя бота, Telegram ID допущенных руководителей и ключ модели.
4. Установить права `chmod 600` на файл секретов.
5. Скопировать службу в `~/.config/systemd/user/`, выполнить `systemctl --user daemon-reload` и `systemctl --user enable --now star-building-strategy.service`.
6. Проверить `strategy_healthcheck.py`, затем открыть точную ссылку бота и нажать **Start**.

Учетные данные запрещено помещать в репозиторий, документацию и журналы.

## Глоссарий

- **Список доступа** — перечень Telegram ID, которым разрешено пользоваться ботом.
- **Polling** — режим, в котором бот сам регулярно получает новые сообщения Telegram.
- **Канонический файл** — основной источник, изменения которого считаются изменением стратегии.
