# 24-marketing-bots: Концепция семейства маркетинговых помощников

Проведен анализ действующих регламентов, организационной структуры, стратегической основы, стандарта клиентского опыта и технических возможностей каналов Instagram, YouTube, LinkedIn и корпоративного сайта.

## Результат

Файл `top_20_marketing_bots.md` содержит:

1. ТОП-10 помощников для Руководителя маркетинга.
2. ТОП-10 помощников для производства материалов и развития узнаваемости.
3. Предварительные кодовые имена по мотивам «Плоского мира».
4. Приоритеты запуска и измеримые показатели.
5. Распределение ответственности по фактической оргструктуре РЕГ-002.
6. Ограничения по согласованию публикаций, фактам, доступам и секретам.

Файл `content_bots_detailed.md` содержит расширенные карточки 10 содержательных помощников: входы, выходы, периодичность, показатели, риски и обязательные точки человеческого согласования.

## Рекомендация

Не создавать сразу 20 отдельных учетных записей. Сначала запустить два контура — «Штаб маркетинга» и «Редакция бренда» — с шестью первоочередными помощниками: `Библиотекарь`, `Таймс`, `Сахарисса`, `Отто`, `Дорфл`, `Гекс`.
