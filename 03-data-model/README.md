# 03-data-model: Модель данных системы кодификации

Каталог содержит описание информационной модели, сущностей, связей и правил проверки данных.

---

## Состав документов

1. `entities.md` — основные сущности системы, их поля, идентификаторы, статусы, связи и правила проверки.
2. `input_and_decisions.md` — структуры входных черновиков, решений агента, предлагаемых правок и журнала действий.
3. `examples.md` — эталонные примеры записей для каждой сущности.
4. `relationships_schema.md` — текстовая схема связей между объектами модели.
5. `assumptions.md` — допущения по полям и структурам, не зафиксированным в первичном задании.
