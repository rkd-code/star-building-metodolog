# 03-data-model: Модель данных и схемы документов

В этой папке хранятся схемы, форматы метаданных и спецификации артефактов базы знаний.

### Планируемая структура:
- `schema_regulation_v1.json` — JSON-Schema структуры 5 разделов регламента.
- `schema_card.json` — схема метаданных карточки регламента для промпта «Карточник».
- `raci_definition.md` — стандарты матрицы распределения ответственности.
- `matrix_ownership.md` — матрица владения процессами компании.
