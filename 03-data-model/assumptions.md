# Допущения по модели данных (MVP v1.0)

В этом документе зафиксированы допущения по структуре полей, которые не были жестко определены в исходном техническом задании:

---

1. **Формат идентификаторов:**
   - Для регламентов принята стабильная маска `РЕГ-ХХХ` (для черновиков: `РЕГ-ХХХ-ЧЕРНОВИК`).
   - Для карточек принята маска `КАРТ-РЕГ-ХХХ`.
   - Для черновиков и логов используется префикс с датой `ГГГГММДД`.

2. **Хранение матрицы ответственности:**
   - На этапе v1.0 матрица ответственности хранится в виде встроенной таблицы внутри текста регламента (Markdown-разметка), а не как отдельная реляционная таблица базы данных.

3. **Связи с нормативными формами:**
   - В Разделе 5 регламента шаблоны документов указываются текстовыми наименованиями. Полноценный справочник кодов форм (например, `ФОРМА-СНАБ-001`) оставлен как допущение для версии v2.0.

4. **Степень вложенности шагов:**
   - В Разделе 3 глубина нумерации алгоритма ограничена двумя уровнями: «Этап N» ➔ «Пункт N.M».
