# 23-code-names: Внутренние имена ботов

Зафиксирована ролевая схема проекта по мотивам вселенной «Плоского мира» Терри Пратчетта.

## Роли

| Участник | Внутреннее имя | Назначение |
|---|---|---|
| Владелец проекта | **лорд Витинари** | Определяет направление развития системы и принимает ключевые решения |
| Бот-кодификатор `@ReglamentSB_bot` | **Смотритель** | Принимает черновики и заявки, проверяет пересечения, формирует проекты регламентирующих документов |
| Бот-консультант `@star_building_help_bot` | **Ом** | Отвечает сотрудникам по утвержденной базе и предлагает только существующие утвержденные формы |
| Помощник-координатор | **Оркестратор** | Помогает лорду Витинари проектировать, настраивать и проверять обоих ботов |

## Порядок начала работы

При постановке задачи без указания конкретного бота Оркестратор предлагает выбор:

1. **Смотритель** — создание регламентов, прием заявок, проверка коллизий, согласование.
2. **Ом** — консультации сотрудников, нормативные ссылки, утвержденные формы.

После выбора все изменения и проверки выполняются только в контуре выбранного бота, если лорд Витинари явно не поручил сквозную задачу.
