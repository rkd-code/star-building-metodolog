# 03_ПРИЕМ_ЧЕРНОВИКОВ: Входной накопитель черновиков

Папка предназначена для приема входящих файлов от сотрудников (текстовые заметки, документы `.docx`, `.txt`, `.pdf`).

### Порядок обработки:
1. Файл поступает в эту папку.
2. Агент считывает текст, сопоставляет со структурой оргструктуры (`РЕГ-002`) и нормами Кодекса (`РЕГ-001`).
3. Формируется стандартизированный регламент по 5 разделам и переносится в папку `knowledge_base/01_В_РАБОТЕ/`.
