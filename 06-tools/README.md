# 06-tools: Утилиты и вспомогательные скрипты

В этой папке размещаются скрипты для сборки, валидации, конвертации и линтинга базы знаний регламентов.

### Планируемые утилиты:
- `validate_raci.py` — проверка соблюдения принципа «ровно один Accountable на процесс».
- `check_cross_references.py` — валидация ссылочной целостности идентификаторов (REG-001..REG-XXX).
- `export_to_docx.py` — конвертер markdown-регламентов в корпоративный шаблон Word (.docx).
- `generate_reestr.py` — автосборка реестра регламентов из карточек.
