# 06-tools: Сервер инструментов и протокол контекста модели

В каталоге спроектирован набор команд и инструментов сервера контекста модели для автоматизации работы агента «Кодификатор».

---

## Состав документов

1. `tools_specification.md` — полная спецификация команд, разбитых на 4 функциональные группы (чтение, анализ, подготовка изменений, выполнение действий).
2. `mcp_server_manifest.json` — архитектурный манифест регистрации сервера инструментов.
3. `assumptions.md` — реестр допущений по среде выполнения и интерфейсам инструментов.
