# 34 — Обязательная документация для всех агентов и репозиториев

## Назначение

Механизм гарантирует, что каждый репозиторий содержит актуальный контекст, структуру файлов, модель данных, решения, базу знаний и ссылки GitHub.

## Как работает

1. Предкоммитный обработчик запускает `ensure_repo_docs.py`.
2. Скрипт создает отсутствующие обязательные документы.
3. Пересобирает машиночитаемый манифест, контекст, структуру и указатель документации.
4. Добавляет обновленные документы в тот же коммит.
5. Проверка GitHub повторно проверяет актуальность после отправки.

## Для всех типов агентов

- `AGENTS.md` читают Hermes, Codex, Claude Code и другие совместимые агенты.
- `.hermes.md` наследуется Hermes из любой подпапки до корня Git.
- Git-проверка действует независимо от профиля и модели агента.

## Для будущих репозиториев

Глобальный шаблон Git устанавливает предкоммитный обработчик при `git init` и `git clone`. При первом коммите обработчик создает полный обязательный комплект документации и версионный скрипт `tools/ensure_repo_docs.py`.

## Ручные команды

```bash
python3 ensure_repo_docs.py --repo /путь/к/репозиторию --stage
python3 ensure_repo_docs.py --repo /путь/к/репозиторию --check
```

## Проверка

```bash
python3 -m unittest -v test_ensure_repo_docs.py
```
