# 30-employee-testing-html: автономная платформа

## Файл для запуска

`index.html` — полностью автономная HTML-платформа «Экзаменатор Star Building».

Откройте файл двойным щелчком в современном браузере. Интернет и установка программы не требуются.

## Возможности сотрудника

- идентификация по табельному номеру или рабочей почте;
- выбор официальной должности отдела продаж;
- случайный порядок вопросов и вариантов;
- сохранение незавершенной попытки в браузере;
- навигация по вопросам;
- автоматический расчет результата;
- проходной порог 90%;
- результат по темам;
- печать результата;
- ограничение: одна попытка в календарный месяц;
- результат действует до запроса РОПа на повторное прохождение.

## Возможности РОПа

- сводка по сотрудникам и попыткам;
- средний балл и доля прошедших;
- таблица результатов;
- настройка числа вопросов в попытке;
- настройка времени прохождения;
- запрос повторного прохождения;
- выгрузка результатов в CSV;
- экспорт и импорт резервной копии в JSON.

Если число вопросов не задано, используется весь банк из 102 вопросов. Если время не задано, ограничение времени не применяется. Это технические значения автономной версии, а не новые корпоративные нормы.

## Хранение данных

Текущая версия хранит данные в `localStorage` конкретного браузера. Данные не синхронизируются между компьютерами.

Перед переносом или очисткой браузера РОП должен создать резервную копию через кнопку «Резервная копия».

## Ограничения автономной версии

- кабинет РОПа не защищен серверной авторизацией;
- правильные ответы физически находятся внутри HTML-файла;
- ограничение попыток действует только в конкретном браузере;
- отсутствует централизованная база сотрудников и результатов;
- нет серверного журнала аудита и резервного копирования.

Для корпоративного развертывания требуется серверная версия с базой данных, корпоративным входом, разграничением прав и хранением правильных ответов на сервере.

## Сборка

HTML воспроизводимо собирается из Excel-банка:

```bash
python3 build_platform.py
```

Источник: `../29-employee-testing-service/question_bank_pool_001.xlsx`.

## Проверка

```bash
python3 -m unittest -v test_build_platform.py
python3 test_browser.py
```

Проверяется:

- наличие 102 вопросов и 408 вариантов;
- один правильный ответ на каждый вопрос;
- порог 90%;
- календарное ограничение попыток;
- отсутствие внешних библиотек и сетевых ресурсов;
- синтаксис сценария;
- сквозное прохождение 102 вопросов в настоящем Chromium;
- формирование результата и строки в кабинете РОПа;
- отсутствие ошибок браузерного сценария.
