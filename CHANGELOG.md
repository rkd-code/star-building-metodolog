# История изменений

## 2026-10-14

- Разработано расширение сопровождения проекта P-026 («Коммерческий департамент») для штаба @Dramknote_bot (FN-014).
- Создано изолированное внеGit/внеprod файловое хранилище решений владельца и версионных черновиков с защитой от path traversal и симлинков (`p026_storage.py`).

- Подтверждена неизменность SHA-256 файлов каталогов 76, 88, 89, 99..102, 106, 107, 109.
- Соблюдена политика NoMergeProdRestartCostsCredentialsACL.

## 2026-08-31

- «Смотритель» и «Ом» переведены из неуправляемых дочерних процессов Hermes в независимые пользовательские службы `systemd` с автоматическим перезапуском.
- Добавлена проверка Telegram API, правильности учетных записей, режима polling и состояния служб.
- Добавлен пятиминутный контроль доступности с уведомлением только при отказе.
- Отключено журналирование адресов Telegram Bot API, содержащих учетные данные.
- Зафиксирована необходимость перевыпуска ранее попавших в историю Git токенов через BotFather.
- Исправлен архив переписки: пустая база нового профиля без таблицы `messages` теперь пропускается, не останавливая автоматическую задачу.
