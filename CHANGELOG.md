# История изменений

## 2026-08-31

- «Смотритель» и «Ом» переведены из неуправляемых дочерних процессов Hermes в независимые пользовательские службы `systemd` с автоматическим перезапуском.
- Добавлена проверка Telegram API, правильности учетных записей, режима polling и состояния служб.
- Добавлен пятиминутный контроль доступности с уведомлением только при отказе.
- Отключено журналирование адресов Telegram Bot API, содержащих учетные данные.
- Зафиксирована необходимость перевыпуска ранее попавших в историю Git токенов через BotFather.

## 2026-08-29

- Введен обязательный стандарт актуальной документации для всех агентов, профилей и репозиториев.
- Добавлены наследуемый контекст Hermes, машиночитаемый манифест, структура проекта и единый указатель документации.
- Подключены автоматическое обновление перед каждым коммитом и независимая проверка GitHub Actions.
- Настроен глобальный шаблон Git для автоматического подключения будущих репозиториев.

## Предыдущие изменения

История архитектурных решений до введения этого журнала хранится в [`DECISIONS.md`](DECISIONS.md), а история Git — в коммитах репозитория.
