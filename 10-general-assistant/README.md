# 10-general-assistant: Универсальный корпоративный агент (Кодификатор + Консультант)

В каталоге зафиксировано расширение концепции и технического задания: переход от инструмента только для методологов к **агенту общего использования для всех сотрудников компании**.

---

## Двухконтурная архитектура системы

```text
                               ┌──────────────────────────────────────────────┐
                               │       ЕДИНЫЙ КОРПОРАТИВНЫЙ АГЕНТ             │
                               └──────────────────────┬───────────────────────┘
                                                      │
                       ┌──────────────────────────────┴──────────────────────────────┐
                       ▼                                                             ▼
     [КОНТУР 1: КОДИФИКАТОР]                                       [КОНТУР 2: КОНСУЛЬТАНТ]
     (Для методологов и руководителей)                             (Для любого сотрудника компании)
     • Прием сырых черновиков                                      • Прием любого вопроса или проблемы
     • Сборка регламентов по 5 разделам                            • Поиск норм в базе регламентов
     • Проверка связей и ролей по РЕГ-003                          • Выдача готового пошагового решения
     • Ведение базы знаний и реестра                               • Авто-генерация шаблона (служебка, акт)
```
