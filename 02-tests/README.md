# 02-tests: Модуль тестирования и валидации регламентов

В этой папке размещаются тестовые сценарии, эталонные черновики (test fixtures) и чек-листы проверки качества работы агента «Кодификатор» по критериям Definition of Done (DoD).

### Планируемая структура:
- `fixtures/` — примеры реальных черновиков (корректные, конфликтные, с неполными данными).
- `checklist_dod.md` — чек-лист ручной и полуавтоматической верификации.
- `assertions.md` — формализованные правила валидации (отсутствие галлюцинаций ролей, точность ссылок на ядро).
