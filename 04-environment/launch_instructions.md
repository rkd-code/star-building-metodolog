# Инструкция по подготовке и запуску окружения

---

## 1. Подготовительный этап (Размещение файлов)

1. Убедиться в наличии директории проекта `/home/roman/` со всеми разделами (`01-report`..`06-tools`).
2. Проверить наличие системного каталога конфигурации `~/.hermes/`.
3. Создать файл секретов на основе шаблона:
   ```bash
   cp 04-environment/env_template.txt ~/.hermes/.env
   chmod 600 ~/.hermes/.env
   ```
4. Внести актуальные ключи доступа в `~/.hermes/.env`.

---

## 2. Проверка конфигурации

1. Применить безопасный шаблон конфигурации:
   ```bash
   cp 04-environment/config_template.yaml ~/.hermes/config.yaml
   ```
2. Проверить корректность структуры каталогов базы знаний:
   - `knowledge_base/00_РЕЕСТР/`
   - `knowledge_base/01_КАРТОЧКИ/`
   - `knowledge_base/02_ПОЛНЫЕ-ТЕКСТЫ/`

---

## 3. Запуск агента

1. Запуск в интерактивном режиме:
   ```bash
   hermes
   ```
2. Запуск в режиме пакетной обработки одного черновика:
   ```bash
   hermes chat -q "Обработай черновик: $(cat путь_к_черновику.md)"
   ```
