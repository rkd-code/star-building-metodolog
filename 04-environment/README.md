# 04-environment: Конфигурация окружения и Claude Project

В этой папке содержатся конфигурационные файлы, шаблоны системных промптов (Custom Instructions) и правила загрузки Project Knowledge в Claude Project.

### Планируемая структура:
- `custom_instructions_kodifikator.md` — итоговый системный промпт для Claude Project.
- `project_knowledge_manifest.yaml` — перечень файлов и порядок их загрузки в контекст проекта.
- `env_settings.md` — требования к окружению и правам доступа пилотной группы пользователей.
