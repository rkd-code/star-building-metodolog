# 04-environment: Окружение агента на сервере Гермеса

В данном каталоге описана архитектура серверного окружения, конфигурации, схемы хранения данных и правила безопасности для развертывания агента «Кодификатор».

---

## Состав документов

1. `structure.md` — изолированные зоны окружения: проект, конфигурации, данные, журналы событий и секреты.
2. `config_template.yaml` — безопасный шаблон конфигурационного файла без реальных ключей.
3. `env_template.txt` — шаблон переменных окружения для ключей доступа.
4. `launch_instructions.md` — пошаговое руководство по подготовке и запуску.
5. `roles_and_permissions.md` — разграничение системных и пользовательских прав доступа.
6. `backup_and_logging.md` — правила резервного копирования, ротации журналов и аудита.
7. `assumptions.md` — зафиксированные допущения по инфраструктуре и серверной среде.
