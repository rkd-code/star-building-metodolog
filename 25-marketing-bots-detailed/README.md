# 25-marketing-bots-detailed: Подробная таблица маркетинговых помощников

## Результат

Подготовлена структурированная книга `marketing_bots_star_building.xlsx` с шестью листами:

1. **Обзор** — архитектурные решения и ограничения.
2. **20 ботов** — подробные карточки всех ранее предложенных помощников.
3. **Уильям де Ворд** — отдельный помощник исследования ниши, болей клиентов и подготовки доказательных статей.
4. **Открытые решения** — проверенные проекты GitHub и их применимость.
5. **Дорожная карта** — последовательность пилота.
6. **Источники** — проверяемые ссылки.

## Выбранное решение для исследования ниши и болей

Ближайший готовый пример — `kushalsamani/social-media-ai-agent`: он формирует исследование рынка, стратегию, календарь, публикации, блоги и материалы для поискового продвижения.[1] Однако проект не обеспечивает требуемую Star Building доказательность болей, работу с корпоративной базой фактов и обязательное согласование.

Поэтому рекомендован составной помощник **«Уильям де Ворд»** на собственной архитектуре:

- `n8n` или `Dify` — управление процессом и согласованиями;[3][4]
- `Crawl4AI` либо `Firecrawl` — сбор законно доступных открытых страниц;[5][6]
- корпоративные обращения, причины отказов, отзывы и кейсы — источник реальных болей;
- `Qdrant` — дополнительный смысловой поиск при росте архива.[7]

`synthetic-market-research` допустим только как генератор гипотез для последующей проверки. Синтетические ответы нельзя представлять как реальные боли клиентов.[2]

## Формат выдачи

По решению пользователя итог предоставляется в Excel. Книга полностью подготовлена и содержит фильтры, закрепленные заголовки, перенос текста и отдельные листы по архитектуре, специальному помощнику, открытым решениям, дорожной карте и источникам.
