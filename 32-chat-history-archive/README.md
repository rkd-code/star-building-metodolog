# Архив переписки Hermes

Система сохраняет переписку пользователя с Hermes по всем профилям в отдельные текстовые файлы.

## Структура

```text
/home/roman/Hermes-переписка/
└── ГГГГ-ММ/
    ├── ГГГГ-ММ-ДД__default.txt
    └── ГГГГ-ММ-ДД__developer.txt
```

На каждый календарный день создается отдельный файл для каждого обнаруженного профиля. Если в профиле в этот день переписки не было, файл содержит соответствующую отметку.

## Состав архива

Включаются:
- сообщения пользователя;
- текстовые ответы Hermes;
- время сообщения;
- название и идентификатор диалога;
- источник переписки.

Не включаются внутренние вызовы инструментов, их технические результаты и служебные сообщения сжатия контекста.

## Время

Дни рассчитываются по часовому поясу `Asia/Almaty`.

## Безопасность

Каталоги создаются с правами `700`, файлы — `600`. Архив может содержать конфиденциальную информацию и не должен публиковаться в Git.

## Запуск вручную

```bash
python3 export_chat_history.py --verbose
```

Повторный запуск безопасен: файл дня полностью пересобирается и не получает дубликатов.
