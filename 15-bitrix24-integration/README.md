# 15-bitrix24-integration: Архитектура интеграции с Битрикс24

В каталоге зафиксирована схема разделения контуров: Telegram (оперативный ввод для сотрудников) + Битрикс24 (согласование и база знаний).

---

## 🏛️ Разделение контуров системы

```text
┌─────────────────────────────────────────────────────────────┐
│                 TELEGRAM (ДЛЯ ВСЕХ СОТРУДНИКОВ)             │
│  • Ветка 1: «Прием черновиков» (голос, текст, файлы)        │
│  • Ветка 2: «Вопросы и консультации» (решения + служебки)   │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                 АГЕНТ (СЕРВЕР ГЕРМЕСА)                      │
│  • Кодификация черновиков по 5 разделам                      │
│  • Поиск ответов по регламентам РЕГ-001..010                │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                 БИТРИКС24 (КОРПОРАТИВНЫЙ КОНТУР)            │
│  • Контур «01_В_РАБОТЕ»: Задачи и бизнес-процессы           │
│    согласования регламентов рабочей группой                 │
│  • Контур «02_УТВЕРЖДЕНО»: Корпоративная База знаний (Wiki) │
│    для опубликованных стандартов Генерального директора     │
└─────────────────────────────────────────────────────────────┘
```

---

## Возможности интеграции с Битрикс24 (REST API / Вебхуки):

1. **Автоматическое создание задач на согласование:**
   - После кодификации черновика агент создает задачу в Битрикс24 с прикрепленным проектом регламента и назначает рабочую группу.
2. **Публикация в Базу знаний (Wiki) Битрикс24:**
   - После команды об утверждении Генеральным директором регламент автоматически публикуется в корпоративную Wiki компании со всеми таблицами и ссылками.
3. **Маршруты согласования (Бизнес-процессы):**
   - Автоматический запуск цепочки согласования (Юристы ➔ HRD ➔ COO ➔ Финальная виза CEO).
