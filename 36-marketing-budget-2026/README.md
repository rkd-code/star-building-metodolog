# 36 — Маркетинговый бюджет до конца 2026 года

Практическая финансовая модель постепенного наращивания маркетинга ТОО «Стар Билдинг» и Grand Construction.

## Артефакты

- `marketing_budget_sep_dec_2026.xlsx` — рабочая Excel-книга: план/факт, каналы, показатели, правила масштабирования и аудит исходника.
- `marketing_budget_approval.docx` — пояснительная записка для утверждения бюджета.
- `BUDGET_RATIONALE.md` — логика бюджета и выводы по исходному файлу.
- `budget_model.py` — единый источник чисел.
- `build_budget.py` — воспроизводимая сборка Excel и DOCX.
- `test_budget_model.py` — проверки баланса и артефактов.

## Бюджет

- операционный маркетинг: **3 000 000 тенге**;
- обязательная цифровая инфраструктура: **49 260 тенге**;
- разовое оборудование: **180 000 тенге**;
- общий предел сентября–декабря: **3 229 260 тенге**.

Бюджет увеличивается только при прохождении измеримых контрольных рубежей. Целевые обращения и тоннаж являются управленческими ориентирами, а не гарантированным прогнозом.

## Сборка и проверка

```bash
python3 build_budget.py
python3 -m unittest -v test_budget_model.py
```
