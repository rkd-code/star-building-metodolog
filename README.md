# Агент «Кодификатор» (Codifier Agent v1.0 MVP)

Система автоматической кодификации и стандартизации бизнес-процессов строительной компании. Проект трансформирует неструктурированные, эмоциональные или неполные черновики от руководителей и прорабов в строгие нормативные регламенты, согласованные с ядровой базой знаний компании.

---

## 🎯 Цели и ключевая ценность

1. **Сокращение времени создания регламента** с нескольких дней до 5–10 минут (первичный драфт v0.1).
2. **Исключение противоречий:** автоматическая проверка пересечений с Кодексом компании (`REG-001`), Регламентом коммуникаций (`REG-002`) и Оргструктурой (`REG-003`).
3. **Единый стандарт:** каждый регламент упаковывается строго в 5 обязательных разделов с матрицей ответственности (RACI) и измеримыми Key Results.
4. **Прозрачность неполноты:** агент не выдумывает недостающие факты (сроки, суммы, формы), а явно подсвечивает их маркером `[ТРЕБУЕТ УТОЧНЕНИЯ]`.

## ⚙️ Архитектурные принципы v1.0 (MVP)

- **Платформа:** `Claude Project` (минимальная инфраструктура, нулевая стоимость разработки на старте).
- **Объем базы знаний:** Пилотная группа из 5–10 регламентов (Ядро + наиболее критичные операционные процессы).
- **Роли пользователей:**
  - *Владелец базы знаний (Заказчик/Методолог):* отбор документов, калибровка промптов, ведение реестра.
  - *Пользователи-авторы (Руководители):* отправка черновиков процессов.
  - *Утверждающие (Руководство компании):* финальное утверждение регламентов вне агента.
- **Главный принцип качества:** Урезаем не качество проработки, а охват (лучше 8 регламентов без ошибок, чем 45 непроверенных).

---

## 🚦 Критерии готовности (Definition of Done)

Версия v1.0 считается успешной при выполнении условий:
1. Выходной документ строго следует структуре из 5 разделов.
2. 0 выдуманных должностей — все роли строго из `REG-003`.
3. Все пересечения с базовыми регламентами оформлены точными ссылками, а не пересказом.
4. Отсутствующие параметры помечены тегом `[ТРЕБУЕТ УТОЧНЕНИЯ]`.
5. Key Results измеримы (числа, сроки, проценты), абстрактные фразы исключены.
