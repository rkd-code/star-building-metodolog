# 14-intake-tool: Инструмент приема и первичной обработки черновиков

В каталоге спроектирован инструмент сбора черновиков от сотрудников и руководителей компании.

---

## 3 канала приема черновиков

1. **Telegram-канал (чат / бот):**
   - Сотрудник отправляет голосовое сообщение, текстовый набросок или файл `.docx` прямо в чат.
   - Система автоматически транскрибирует аудио и запускает кодификацию по 5 разделам.

2. **Входная папка на сервере (`knowledge_base/03_ПРИЕМ_ЧЕРНОВИКОВ/`):**
   - Автор или методолог сохраняет файл черновика в папку `03_ПРИЕМ_ЧЕРНОВИКОВ/`.
   - Серверный скрипт автоматически считывает файл, сопоставляет роли с `РЕГ-002` и формирует проект регламента в папке `01_В_РАБОТЕ`.

3. **Веб-форма быстрой подачи (HTML-интерфейс):**
   - Легкая форма в браузере: поля «Автор», «Подразделение», «Тема процесса», поле текста/файла и кнопка «Отправить на кодификацию».
