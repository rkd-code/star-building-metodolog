# 05-integrations: Архитектура будущих интеграций (Roadmap v2.0+)

В рамках MVP v1.0 прямые программные интеграции сознательно исключены. Данный каталог зарезервирован под проектирование будущих коннекторов.

### Перспективные интеграции (v2.0):
- `telegram_bot/` — бот для приема голосовых и текстовых черновиков от прорабов и линейных руководителей.
- `bitrix24/` — экспорт утвержденных регламентов в корпоративную базу знаний Битрикс24 / Wiki.
- `edo_approvals/` — маршруты электронного согласования документов в СЭД / 1С:ДО.
- `slack_claude_tag/` — интеграция через Claude Tag в выделенном канале Slack.
