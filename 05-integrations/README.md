# 05-integrations: Архитектура внешних интеграций

В каталоге зафиксирована архитектура взаимодействия агента с внешними системами, потоки данных, протоколы надежности и разграничение функционала по версиям.

---

## Состав документов

1. `systems_catalog.md` — каталог внешних систем с детальным описанием потоков данных, прав, ошибок и правил подтверждения человеком.
2. `data_flow_map.md` — карта сквозного движения данных между пользователями, агентом и корпоративными системами.
3. `version_scope.md` — матрица разделения интеграций первой версии (v1.0) и последующих этапов (v2.0+).
4. `assumptions.md` — допущения по протоколам, авторизации и внешним интерфейсам.
