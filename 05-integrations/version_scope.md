# Матрица разделения интеграций по версиям

| Направление интеграции | Первая версия (v1.0 MVP) | Следующие версии (v2.0+) |
|---|---|---|
| **Подача черновиков** | Вручную через веб-интерфейс проекта | Telegram-бот (текст + голос), почтовый шлюз |
| **База знаний** | Файлы проекта в Claude Project + локальная папка | Корпоративная база знаний Битрикс24 / Wiki |
| **Оргструктура и роли** | Статичный файл `РЕГ-003` в базе знаний | Авто-синхронизация со штатным расписанием из 1С:ЗУП |
| **Согласование и визирование** | Вне системы (ручные совещания и подписи) | Маршруты согласования в 1С:Документооборот / СЭД |
| **Оповещение исполнителей** | Ручная рассылка методологом | Автоматическая рассылка в рабочие чаты площадок |
| **Аудит и логирование** | Локальные файлы журналов на сервере | Корпоративная система сбора и анализа логов |
