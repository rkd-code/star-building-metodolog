# Допущения по внешним интеграциям (MVP v1.0)

В данном документе зафиксированы допущения и отложенные развилки по интеграционному контуру:

---

1. **Исключение сетевых коннекторов в первой версии:**
   - Для v1.0 исключены любые прямые программные интеграции с внешними корпоративными системами (Telegram Bot API, Битрикс24 REST API, веб-сервисы 1С).
   - Взаимодействие ограничено передачей текста черновика через интерфейс проекта.

2. **Формат передачи данных для v2.0:**
   - Предполагается, что к моменту разработки v2.0 корпоративные системы компании будут поддерживать стандартные защищенные протоколы (HTTPS, REST API, JSON).

3. **Право первой подписи:**
   - Агент никогда не наделяется правом автоматической публикации или утверждения регламентов без прямого подтверждения человеком-методологом.

4. **Голосовой ввод:**
   - Голосовой ввод черновиков от прорабов на стройплощадках отложен на версию v2.0 и будет использовать серверные механизмы распознавания речи.
